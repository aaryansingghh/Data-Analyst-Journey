# Power BI

This folder contains my Power BI dashboards and projects.

## Projects

### 1. UPI Transaction Data Analysis Dashboard

Analyzed 20,000 UPI transactions to explore transaction trends, transaction amounts, remaining balances, and customer/payment patterns.

**Key Analysis:**
- Monthly transaction trends
- City-wise analysis
- Bank-wise analysis
- Device type analysis
- Age group and gender analysis
- Payment method and purpose analysis
- Transaction type analysis

**Power BI Features:**
- Line Charts
- Column Charts
- Matrix/Table
- Slicers
- Bookmarks

---

### 2. Sales Data Analysis

Analyzed 3,510 sales transactions with supporting customer, product, and promotion data.

**Key Analysis:**
- Top 5 and Bottom 5 products
- Sales, Profit and Quantity analysis
- City-wise sales
- Sales trends
- Promotion and discount analysis
- Profit vs Net Sales
- Date-period comparison

**Power BI Features:**
- Interactive dashboards
- Filters and slicers
- Visual interactions
- Date comparisons
- Detailed transaction table
